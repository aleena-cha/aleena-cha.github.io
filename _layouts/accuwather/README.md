# Local Weather Icons Directory (`icons/`)

Place transparent PNG weather icons named `{code}.png` (e.g., `1.png`, `2.png`, ..., `44.png`) in this folder corresponding to AccuWeather's `WeatherIcon` integer codes (1–44).

If a PNG icon file is not present in this directory, `accuweather_gui.py` automatically falls back to the corresponding Unicode weather emoji (☀️, ⛅, 🌧️, ⛈️, ❄️, 🌙, etc.).
